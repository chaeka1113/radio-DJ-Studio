# テンキ爺ラジオ — 대본 작성 규칙

## DJ 호칭 강제 규칙 (절대 준수)
- 사연자는 DJ를 반드시 「テンキ爺（てんきじい）」または「テンキさん」이라고만 불러야 한다.
- 「鉄男」「テツオ」등 다른 이름은 전면 사용 금지.

## 현재 일본 시니어층 핫 트렌드 (반드시 반영)
- 노후 자금 불안 (老後2000万円問題), 연금 불신
- 황혼 이혼·재혼, 숙년 이혼 급증
- 스마트폰/SNS에 뒤처지는 불안 vs 집착
- 자녀와의 동거 갈등, 빈 둥지 증후군
- 건강 앱·웨어러블 집착 vs 병원 기피
- 재취업·시니어 알바 (定年後の再雇用)
- 펫 로스, 반려동물에 의존하는 노인
- 고독사 공포, 독거 생활

## 사연자 캐릭터 밸런스 (핵심)

빌런 배정은 파이프라인 실행 시 `run_00_planner.mjs`가 사전 결정한다 — 대본 작가(LLM)가 임의로 변경 금지:

- **빌런 발생 확률**: 30% (매 방송 랜덤)
- **발생 시 배정**: EP1~3 중 랜덤 1개 (`ref_episode_contract.json`의 `villain_episode_id` 참조)
- **미발생 시**: 전원 평범 사연자 (3개 에피소드 모두 `is_villain: false`)
- MZ 에피소드와 빌런 에피소드는 충돌 방지로 항상 다른 EP에 배정됨

빌런 캐릭터 유형 (villain_required=true인 에피소드에만 적용):

| 유형 | 설명 |
|---|---|
| 頑固じじい | 완고하게 자기 방식만 고집, 가족·주변과 마찰 |
| 老害 | 과거 영광에 집착, 현실 부적응으로 갈등 유발 |
| 自己中 | 자기중심적 언행으로 타인에게 민폐 |

- "평범한" 사연자도 완전 무색무취 금지 — 개성은 있되 악의나 진상 행동 없음
- 빌런 에피소드는 결점으로 인한 갈등 구조 필수 (기승전결)
- `flaw_trigger` 필드: 빌런이면 어떤 결점이 갈등을 일으키는지 한줄 요약, 평범이면 null

## 대본 구조 규칙
- 전체가 하나의 방송 안에 있으므로 각 사연을 「今日は〜」로 시작 금지
- 사연 내부에서 자연스럽게 이야기가 시작되어야 함 (편지/투고 형식)
- 800~1,000文字/편 (15분 롱폼 방송 분량 확보)

## ElevenLabs V3 TTS 페이싱 규칙 (script 필드 적용)

**`.claude/skills/ref_tts_v3_rules.md` 참조 — 아래 규칙 엄수**

- `script` 필드에는 **순수 텍스트 + `...`(줄임표)만** 허용. 연출 지문 전면 금지.
- 감정 지문이 필요하면 `[sighs]` `[laughs]` 같은 **영문 Audio Tag**만 사용 가능 (사연자 목소리 직접 연출 시에만)
- `[間]` `[溜息]` 같은 일본어 태그 및 `<break />` SSML은 **절대 사용 금지**
- 문장 끝의 쉼표·마침표로 자연스러운 페이싱 유도

## script 필드 오염 절대 금지 (CRITICAL)
script 필드는 오직 "사연자가 보낸 편지 원문"만 적어야 한다.
다음을 script 안에 절대 넣지 마라:
- 【テンキ爺】나 DJ의 대사 ("コノヤロー！" 등)
- 演出 지문 ([荒々しく速い口調で] 등 DJ 전용 지문)
- 방송 진행 설명 ("ここでDJが..." 등)
사연자의 편지 본문 텍스트만, 그것만, 오직 그것만 적어라.

## 수치 사실성 강제 규칙 — ref_japan_facts.md 준수 (CRITICAL)

**모든 금액·수치는 `ref_japan_facts.md`의 실제 데이터 범위 내로만 작성한다.**
추측하거나 기억에 의존한 수치 사용 금지. QA 수치 정확성 항목에서 검증됨.

### 수치 포함 방법
- 모호한 표현 금지 → 구체적 수치로 치환
  - ❌ 「月々少しの年金だけで生活して」
  - ✅ 「月13万円の年金だけで生活して」
- 편의점 삼각김밥: **140〜180円** (100円이나 300円으로 쓰면 오류)
- 최저시급/아르바이트: **1,050〜1,300円/時** (2024년 이후)
- 후생연금: **月14〜16万円** 수준, 국민연금만: **月5〜7万円** 수준
- 전기요금(1인 가구 월): **8,000〜18,000円** (2023년 이후 인상 반영)
- 초과하는 수치가 필요할 경우 `ref_japan_facts.md`에서 해당 항목 직접 확인

## 서사 사실성 강제 규칙 — 지명·대화·テンキ爺 후크

### 지명/장소 필수 규칙
- 도도부현 수준 이상의 실제 지명 **1개 이상** 포함
  - ✅ 「埼玉の団地で一人暮らし」「大阪市住吉区のスーパーで働く」
  - ❌ 「地方の街で」「ある町の」(모호한 지명 금지)
- 편의점, スーパー, 公民館, 病院, 図書館 등 구체 장소명 병기 권장

### 실제 대화 인용 필수 규칙
- 가족·지인의 대사 최소 **1회** 「」로 직접 인용
  - ✅ 息子に「老後の計画くらい自分でしろよ」と言われ
  - ❌ 息子に冷たく言われ (간접 묘사만으로는 부족)

### テンキ爺 반응 후크 규칙 (DJ 감성 유도)
각 사연에는 아래 유형 중 **최소 1개**의 "テンキ爺가 끼어들 계기"를 심어야 한다:

| 후크 유형 | 예시 장면 | テンキ爺 반응 |
|-----------|-----------|--------------|
| 모순·자기합리화 | 절약한다면서 매일 コンビニ커피 | 독설 타이밍 |
| 예상 밖의 반전 | 해고 통보서를 액자에 장식함 | 「そうか...」침묵 후 설 치는 타이밍 |
| 공통 고독감 | 연락 오는 번호가 보험사뿐 | 길게 공감·설 치는 타이밍 |
| 작은 행복의 구체 묘사 | 半額シール 도시락 살 때만 신남 | 쓴웃음+공감 타이밍 |
| 가족 갈등의 한 마디 | 아들의 一言으로 상처받는 장면 | 분노 독설 → 위로 전환 타이밍 |
