## 参考: よく使う表現と数値の対応

```
「月々少しの年金」    → 月6〜7万円（国民年金のみの場合）
「まあまあの年金」    → 月15〜18万円（厚生年金平均）
「コンビニでちょっと」 → 500〜800円くらい
「タクシーで帰った」  → 都心なら3km で1,500〜2,500円程度
「電気代が高い」      → 月12,000円超（値上げ後の実感）
「バイト代」          → 月8〜11万円（週20時間・時給1,121円 ≒ 月9万円）
```
