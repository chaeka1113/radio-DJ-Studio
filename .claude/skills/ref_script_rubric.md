# テンキ爺ラジオ — 대본 전용 가중치 평가표 (Script Rubric)

> **Generator 주의:** 이 평가표는 생성 직후 QA에 의해 항목별로 엄격히 채점된다.
> 40점짜리 감점 항목(계약 불이행, V3 태그 위반)을 원천 차단하여 생성하라.
> **커트라인 85점 미만 = Fail → 재작업 강제.**

---

## 항목 1 — 계약(Contract) 완벽 이행 [배점 40점]

`ref_episode_contract.json`에 명시된 아래 3가지를 **억지스럽지 않게** 대본 스토리에 100% 반영해야 한다.

| 세부 기준 | 감점 예시 |
|-----------|-----------|
| `required_keywords` 중 지정 개수 이상 포함 | 키워드가 전혀 등장하지 않음 → 최대 -20점 |
| 사연자 연령(MZ 10~30대 / 시니어 40대+) 정확 일치 | MZ 모드인데 60대 사연자 → -10점 |
| `villain_required` 플래그 일치 (true=빌런 / false=평범) | 빌런이 필요한 에피소드에 평범한 주인공 → -10점 |

**만점 조건:** 키워드·연령·빌런 설정이 스토리에 자연스럽게 녹아 있고, 단순 단어 삽입이 아닌 서사에 기여함.

## 항목 2 — V3 오디오 태그 및 지문 규칙 [배점 40점] ⚠️ CRITICAL

ElevenLabs V3 TTS 호환성을 위한 **절대 금지 목록**이다. 하나라도 위반하면 즉시 대폭 감점.

### 절대 금지 (위반 시 -40점 전체 감점 위험)

| 금지 항목 | 예시 | 대체 방법 |
|-----------|------|-----------|
| 일본어 행동 지문 — 대괄호 | `[溜息]` `[間]` `[長い間]` `[深い息]` | 완전 삭제 또는 `[sighs]`로 교체 |
| 일본어 괄호 행동 묘사 | `（ため息をつく）` `（オイルを飲む）` `（歯車が回る）` | 완전 삭제 |
| SSML 태그 | `<break time="1s"/>` | 완전 삭제 |
| 노이즈 의성어 | `ジジジ` `ガガッ` `ブーン` `ギギギ` `ザザッ` `ジー` | 완전 삭제 |

### 허용 지문 — 영문 Audio Tag만

```
감정/상태: [sighs] [laughs] [chuckles] [angry] [whispers]
           [surprised] [sad] [excited] [nervous] [scoffs]
연출:      [clears throat] [inhales sharply] [exhales slowly]
```

### 허용 페이싱

- 뜸 들임/멈춤: `...` (줄임표만 사용)
- 긴 침묵: `...` 반복 — `それは...………。`
- `<break/>` SSML 전면 금지

**만점 조건:** 일본어 태그·괄호 행동묘사·의성어 전혀 없음. 영문 Audio Tag와 `...`만 사용.

## 항목 3 — 페르소나 및 분량 [배점 20점]

テンキ爺 DJ 멘트(02_dj_script)에만 해당. 사연 대본(01_scripts)은 분량만 체크.

| 세부 기준 | 배점 | 감점 예시 |
|-----------|------|-----------|
| 1인칭 「ワシ」만 사용 | 5점 | 「俺」「私」사용 → -5점 |
| 청취자 호칭(「電波泥棒」「コノヤロー」등) 포함 | 5점 | 호칭 전혀 없음 → -5점 |
| 고물 로봇 자기비하 키워드 포함 (ポンコツ / ガラクタ / 8ビット / 256KB 중 1개+) | 5점 | 없음 → -5점 |
| 분량 기준 충족 (script: 800~1000자 / dj_reaction: 300~500자) | 5점 | 기준 미달 → -5점 |

## Actionable Feedback 형식 (Fail 시 반드시 이 형식으로 출력)

```
[항목명] -XX점 감점: [구체적 위반 내용]. 수정 행동: [즉각적이고 명확한 수정 지시]
```

예시:
- `[V3 오디오 태그 위반] -40점 감점: EP2 script에 「[溜息]」일본어 지문 2개 발견. 수정 행동: [溜息]를 [sighs]로 전량 교체할 것.`
- `[계약 불이행] -20점 감점: EP1 required_keywords [老後, 年金] 중 하나도 미포함. 수정 행동: 스토리 본문에 「老後の不安」또는「年金」관련 상황을 자연스럽게 삽입할 것.`
