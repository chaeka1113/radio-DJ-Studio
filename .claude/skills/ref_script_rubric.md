# テンキ爺ラジオ — 대본 전용 가중치 평가표 (Script Rubric)

> **Generator 주의:** 이 평가표는 생성 직후 QA에 의해 항목별로 엄격히 채점된다.
> 특히 항목 2(V3 태그 위반)와 항목 3(서사 사실성)을 원천 차단하여 생성하라.
> **커트라인 85점 미만 = Fail → 재작업 강제.**

---

## Stage 1 — 프로그래매틱 즉시 Fail 항목 (점수 무관)

아래 항목은 Stage 2 루브릭 채점 **전** Stage 1에서 코드로 검출하여 **총점과 무관하게 즉시 Fail** 처리.
단 1건이라도 해당되면 `01_qa_feedback.json` 저장 → 파이프라인이 `01_script` 재실행(최대 3회).

| 검사 항목 | 판정 기준 | 영향 에피소드 |
|-----------|-----------|--------------|
| 비허용 Audio Tag | script 필드에 허용 목록 외 영문 태그 (`[happy]` `[calm]` 등) | 해당 EP Fail |
| 빌런 전용 Tag 오용 | `[angry]` `[scoffs]`를 `is_villain=false` 캐릭터가 사용 | 해당 EP Fail |
| 캐릭터 이름 중복 | EP1·EP2·EP3 중 `character.name` 완전 동일 값 2개 이상 | 중복 EP 전부 Fail |

**Generator에게**: 위 3가지 위반은 점수로 구제 불가. 생성 단계에서 원천 차단하라.

## 항목 1 — 계약(Contract) 완벽 이행 [배점 25점]

`ref_episode_contract.json`에 명시된 제약을 **억지스럽지 않게** 대본 스토리에 반영해야 한다.

| 세부 기준 | 배점 | 감점 예시 |
|-----------|------|-----------|
| `required_keywords` 중 지정 개수 이상 포함 | 15점 | 키워드 전혀 없음 → -15점 |
| 사연자 연령 정확 일치 (MZ/시니어) | 5점 | MZ 모드인데 60대 사연자 → -5점 |
| `villain_required` 플래그 일치 | 5점 | 빌런 필수인데 평범한 주인공 → -5점 |

**만점 조건:** 키워드·연령·빌런 설정이 스토리 서사에 자연스럽게 녹아 있음. 단순 단어 삽입 X.

## 항목 2 — V3 오디오 태그 및 지문 규칙 [배점 35점] ⚠️ CRITICAL

ElevenLabs V3 TTS 호환성을 위한 **절대 금지 목록**. 하나라도 위반하면 즉시 대폭 감점.

### 절대 금지 (위반 시 -35점 전체 감점 위험)

| 금지 항목 | 예시 | 대체 방법 |
|-----------|------|-----------|
| 일본어 행동 지문 — 대괄호 | `[溜息]` `[間]` `[長い間]` | 완전 삭제 또는 `[sighs]`로 교체 |
| 일본어 괄호 행동 묘사 | `（ため息をつく）` `（オイルを飲む）` | 완전 삭제 |
| SSML 태그 | `<break time="1s"/>` | 완전 삭제 |
| 노이즈 의성어 | `ジジジ` `ガガッ` `ブーン` `ギギギ` `ザザッ` | 완전 삭제 |

### 허용 지문 — 영문 Audio Tag

**DJ 멘트 필드** (제한 없음):
```
[sighs] [laughs] [chuckles] [angry] [whispers] [surprised]
[sad] [excited] [nervous] [scoffs] [clears throat]
[inhales sharply] [exhales slowly]
```

**script 필드 (사연자 편지)** — 제한적 허용:
```
기본: [sighs] [laughs] [chuckles] [sad] [nervous] [excited] [surprised] [whispers]
빌런 한정: [angry] [scoffs]
금지: 효과음 계열([applause] 등), 일본어 태그, SSML
```
사용 기준: 800〜1,000字 당 1〜3개, 감정 절정에만, 연속 사용 금지.

**만점 조건:** 일본어 태그·괄호·의성어 전혀 없음. script 필드 Audio Tag 1개 이상 포함(필수).
**감점:** script 필드에 Audio Tag가 하나도 없으면 -8점.

## 항목 3 — 서사 사실성 및 수치 정확성 [배점 25점] ← NEW

사연이 실제 일본인이 보낸 편지처럼 읽히는가를 검증한다.
`ref_japan_facts.md`를 참조하여 수치의 현실성을 판단한다.

| 세부 기준 | 배점 | 검증 방법 |
|-----------|------|-----------|
| 구체적 지명/장소 1개 이상 | 5점 | 도도부현·시구정촌·店名 중 1개 이상 포함 여부 |
| 수치의 현실성 | 10점 | ref_japan_facts.md 범위 내 수치 사용 여부 |
| 실제 대화 인용 1회 이상 | 5점 | 「」로 감싼 직접 인용 대사 최소 1회 포함 여부 |
| テンキ爺 반응 후크 1개 이상 | 5점 | 독설·공감·설 치는 계기가 되는 전환점 존재 여부 |

### 수치 검증 기준 (ref_japan_facts.md 기반)

| 항목 | 허용 범위 | 오류 예 |
|------|-----------|---------|
| 편의점 おにぎり | 140〜180円 | 100円, 300円 |
| 후생연금 수령액 | 月14〜16万円 | 月5万円, 月30万円 |
| 국민연금만 수령 | 月5.5〜6.7万円 | 月12万円 |
| 아르바이트 시급 | 1,050〜1,300円 | 800円, 2,000円 |
| 1인 전기요금 | 月8,000〜18,000円 | 月3,000円, 月30,000円 |

**감점 기준:**
- 지명 없음: -5점
- 수치가 범위를 크게 벗어남(50% 이상 차이): -5〜10점
- 대화 인용 없음: -5점
- テンキ爺 후크 없음: -5점

## 항목 4 — 분량 [배점 15점]

| 세부 기준 | 배점 | 감점 예시 |
|-----------|------|-----------|
| script 필드 800〜1,000字 | 15점 | 800字 미만 → -10점 / 1,000字 초과 → -5점 |

**주의:** 분량은 검증 최소 기준. 800자를 채우기 위한 의미 없는 반복·나열은 항목3(서사사실성)에서 감점됨.

## Actionable Feedback 형식 (Fail 시 반드시 이 형식으로 출력)

```
[항목명] -XX점 감점: [구체적 위반 내용]. 수정 행동: [즉각적이고 명확한 수정 지시]
```

예시:
- `[V3 오디오 태그 위반] -35점 감점: EP2 script에 「[溜息]」일본어 지문 2개 발견. 수정 행동: [溜息]를 완전 삭제하거나 문장 구조로 감정 표현할 것.`
- `[수치 오류] -10점 감점: EP1 「おにぎり100円」→ 실제 140〜180円 범위 벗어남. 수정 행동: 「おにぎり150円」으로 수정.`
- `[テンキ爺 후크 없음] -5점 감점: EP3 사연에 DJ가 반응할 전환점이 없음. 수정 행동: 주인공의 모순된 행동이나 예상 밖의 반전 장면 1개 추가.`
